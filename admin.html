Perbarui katalog promo

Upload stok harian, lalu unduh katalog.json dan upload ke repo GitHub. Halaman customer otomatis menampilkan stok terbaru. Semua proses berjalan di browser, file tidak dikirim ke server mana pun.

Upload stok harian→Buat katalog→Upload katalog.json ke GitHub
1

List artikel promo

Dibaca dari promo.json di repo. Cukup diganti saat list promo berubah (misalnya awal bulan): pilih file promo, pilih sheet, lalu unduh promo.json dan upload ke repo.

Memeriksa promo.json…
Ganti dengan file promo baru (.xlsx)
2

Foto produk

Dibaca dari gambar.json di repo, format sama dengan tools Stock Display Check, jadi file yang sudah ada bisa langsung dipakai. Ganti hanya saat ada master foto baru.

Memeriksa gambar.json…
Ganti dengan master foto baru (.xlsx)
3

Stok harian

Upload export stock by bin semua toko. Yang dihitung hanya stok available di bin saleable, sesuai zone yang dicentang. Lokasi bazaar dilewati karena promo bazaar punya list sendiri.

4

Buat katalog

Stok dicocokkan dengan list promo per artikel (SKU), lalu dikelompokkan per produk dan warna lengkap dengan foto.

  1. Buka repo GitHub katalog, klik Add file → Upload files, lalu upload katalog.json (timpa file lama).
  2. Klik Commit changes, tunggu 1–2 menit, lalu buka halaman katalog dan tekan Ctrl+F5.
