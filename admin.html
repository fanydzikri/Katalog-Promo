Perbarui katalog promo

Upload stok harian, lalu unduh katalog.json dan upload ke repo GitHub. Halaman customer otomatis menampilkan stok terbaru. Semua proses berjalan di browser, file tidak dikirim ke server mana pun.

Upload stok harian→Buat katalog→Upload katalog.json ke GitHub
Halaman admin ini versi lama (masih tersimpan di cache browser). Katalog yang dibuat dari halaman ini tidak memuat fitur terbaru.
Terbitkan langsung belum aktif
Hubungkan ke GitHub sekali saja, setelah itu katalog terbit dengan satu klik tanpa upload manual.
  1. Buka github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Token name: Admin Katalog. Expiration: pilih Custom, misalnya 1 tahun.
  3. Repository access: Only select repositories → pilih Katalog-Promo.
  4. Permissions → Repository permissions → Contents: Read and write. Yang lain biarkan.
  5. Klik Generate token, salin token (diawali github_pat_), lalu tempel di bawah.

Token hanya disimpan di browser laptop ini, tidak ikut ke repo. Jangan pernah menempelkan token di index.html atau admin.html.

4

Stok harian

Upload export stock by bin semua toko. Yang dihitung hanya stok available di bin saleable, sesuai zone yang dicentang. Lokasi bazaar dilewati karena promo bazaar punya list sendiri.

5

Buat katalog

Stok dicocokkan dengan master artikel dan list promo per artikel (SKU), lalu dikelompokkan per produk dan warna lengkap dengan foto. Hanya artikel yang punya harga yang ditampilkan. Artikel tanpa harga, tidak ada di master, atau barang non-jual (paper bag, shopping bag) dianggap bukan barang jual.

Terbit otomatis belum aktif. Hubungkan GitHub sekali saja, setelah itu katalog langsung tayang setiap kali stok diupload, tanpa unduh dan upload manual.
Atau upload manual ke GitHub
  1. Buka repo GitHub katalog, klik Add file → Upload files, lalu upload katalog.json (timpa file lama).
  2. Klik Commit changes, tunggu 1–2 menit, lalu buka halaman katalog dan tekan Ctrl+F5.
